# Página web de cumpleaños

Proyecto estático en HTML, CSS y JavaScript.

## Estructura

cumple_web/
├── index.html
├── styles.css
├── script.js
└── assets/
    ├── fotos/
    │   ├── foto1.svg
    │   ├── foto2.svg
    │   ├── foto3.svg
    │   ├── foto4.svg
    │   └── foto5.svg
    └── audio/
        ├── musica.mp3
        ├── mensaje1.mp3
        ├── mensaje2.mp3
        └── mensaje3.mp3

## Para personalizar

1. Cambia "Nombre" dentro de index.html.
2. Cambia el mensaje principal y la firma.
3. Sustituye las imágenes de assets/fotos.
4. Añade tus MP3 dentro de assets/audio.
5. Para conservar el código sin modificar, puedes reemplazar los SVG por JPG y cambiar en index.html:
   foto1.svg -> foto1.jpg, etc.

## Ejecutar

Abre la carpeta en Visual Studio Code.
Instala la extensión Live Server.
Abre index.html y pulsa "Go Live".

## Publicar

Puedes usar GitHub Pages porque el proyecto es completamente estático.
